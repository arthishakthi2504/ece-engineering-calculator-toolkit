# ECE Engineering Calculator & Toolkit

A web-based engineering utility platform designed for Electronics and Communication Engineering students, electronics enthusiasts, and learners.

## 🌐 Live Demo

https://ece-electronics-calc-5uzd.bolt.host

## 📌 About the Project

The ECE Engineering Calculator & Toolkit brings commonly used electronics and engineering calculations into a single accessible platform.

The project was developed to make frequently used formulas easier to calculate, understand, and reference.

## ⚙️ Features

* Basic Calculator
* Scientific Calculator
* Ohm's Law Calculator
* Power Calculator
* LED Resistor Calculator
* Resistor Color Code Calculator
* 555 Timer Calculator
* Frequency ↔ Wavelength Calculator
* Antenna Length Calculator
* dB / dBm / dBW Calculator
* Battery Runtime Calculator
* Solar Power Calculator
* Binary / Decimal / Hex Converter
* Engineering Unit Converter
* Formula Reference
* Step-by-Step Calculation Explanations
* Calculation History
* Favorites
* Engineering Workspace
* Responsive Mobile and Desktop Interface

## 🛠️ Technologies

* React
* TypeScript
* Tailwind CSS
* Bolt
* Web Application Development

## 🎯 Purpose

The main objective of this project is to provide a simple and accessible engineering utility for students and learners working with electronics and communication engineering concepts.

## 📱 Deployment & Testing

The application has been publicly deployed and tested across different devices to verify responsive operation and accessibility.
